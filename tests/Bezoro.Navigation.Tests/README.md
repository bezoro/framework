# Bezoro.Navigation.Tests

Contract and regression tests for [Bezoro.Navigation](../../src/Bezoro.Navigation/README.md). Tests run without launching Unity or Godot.

```sh
dotnet test tests/Bezoro.Navigation.Tests/Bezoro.Navigation.Tests.csproj -c Release
```

See the module's documentation for ownership, capacity, and numeric contracts. These managed tests do not replace validation in engine player builds.
